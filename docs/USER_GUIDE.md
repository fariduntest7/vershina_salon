# Руководство пользователя

## Что умеет продукт

- управление клиентами
- календарь записей
- расчёт доходов и расходов
- управление мастерами и услугами
- локальные уведомления
- резервное копирование

## Использование

1. Откройте проект.
2. Запустите приложение.
3. Пройдите onboarding.
4. Авторизуйтесь или создайте локального пользователя.
5. Используйте dashboard и модули управления.
