# PLATFORM_SUPPORT

## Android

- native support
- SQLite / Drift
- Android permissions

## iOS

- native support
- SQLite / Drift
- local auth и notifications

## Windows

- desktop support
- локальная БД и маршрутизация

## Web

- IndexedDB + Drift Web
- offline-first через browser storage

## Ограничения

Полный стабильно работающий runtime требует отдельной проверки на каждом target после завершения финальной реализации.
