# Тестирование

В проекте предусмотрены следующие уровни проверки:

- unit tests — расчёты, валидация, логика складских остатков
- widget tests — формы и экраны
- integration tests — сценарии создания клиента, записи и финансовых действий
- database tests — миграции, резервные копии и восстановление

## Рекомендуемые команды

```bash
flutter test
flutter test test/unit
flutter test test/widget
flutter test test/database
```

## Ограничения

Полный набор тестов будет завершён после подготовки полноценного локального environment и миграций БД.
